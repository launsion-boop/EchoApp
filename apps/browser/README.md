# Browser

Browser is the EchoBraid Chromium browser factory app copied into the EchoApp catalog.

It provides:

- A Chromium-backed browsing surface with persistent session state.
- Tabs, navigation, refresh, address entry, and history-aware autocomplete.
- An EchoAgent sidebar that can work with the current page context.
- EchoBraid platform theme and locale integration.

The source copy is taken from `launsion-boop/echobraid` at `packages/factory-apps/browser` and repackaged for EchoApp update delivery.
